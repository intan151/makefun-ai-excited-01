A golden koi leaps up a moonlit waterfall toward the full moon — one
deterministic Python 3.13 program (standard library only) draws the image.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=out python3.13 main.py
```

It writes a single 768x768 PNG to `$MAKEFUN_OUTPUT_DIR/entry.png`.
